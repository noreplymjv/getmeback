GetMeBack — click to run (works after you move it)
==================================================

Copy or move the WHOLE folder together (USB stick, another PC, renamed folder,
another drive). Do not pick out a single file. After moving, click START —
not only GetMeBack.html.

Computers
---------
Browsers block Flutter apps from a raw file:// double-click.

  Windows:  double-click  START GetMeBack.bat
  Mac:      double-click  START GetMeBack.command
  Linux:    double-click  START GetMeBack.sh

That starter opens GetMeBack.html in your browser from a tiny local server.
Leave the black/terminal window open while you play. Close it to quit.

Phones
------
HTML will not run from the Files app. Install Phone/GetMeBack.apk instead.

Keep every file in this folder together. GetMeBack.html needs the assets
next to it. The starters always use files in the same folder they sit in,
so the folder still works after you move or rename it.
