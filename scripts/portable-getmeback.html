GetMeBack

This app cannot start from a raw HTML double-click. After you copy or move this whole folder, click the START file next to this page — it opens GetMeBack in your browser.

Windows: double-click START GetMeBack.bat

Mac: double-click START GetMeBack.command

Linux: double-click START GetMeBack.sh

Phone: install GetMeBack.apk from the Phone folder (HTML will not run from Files).
